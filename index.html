How It Works
Three steps. Zero traces.

No installs, no accounts, no lasting footprint. Just a document that exists long enough to be printed.

01
Upload & Encrypt

Your file is encrypted right in your browser using AES-256-GCM. The decryption key is embedded in the URL fragment — it never reaches our server.

02
Share the Link

Send the one-time link via WhatsApp, SMS, or show the QR code in person. The shopkeeper opens it in any browser — no app needed on either side.

03
Opens Once, Gone Forever

First open decrypts and renders the document for printing. Immediately after, the file is permanently deleted. The link dies. No trace remains.
